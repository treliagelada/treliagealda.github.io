How to Compile Your Own RustDesk Custom Windows Client

This guide provides step-by-step instructions for compiling a custom RustDesk Windows client from source. RustDesk is an open-source remote desktop software written in Rust.

Prerequisites

1. Install Development Tools

  • Visual Studio 2022 with C++ development tools
    • Download from https://visualstudio.microsoft.com/
    • During installation, select "Desktop development with C++"
  • Rust toolchain
    • Download and install from https://rustup.rs/
    • Run the installer and follow the prompts
  • Git for version control
    • Download from https://git-scm.com/

2. Install Required Dependencies

Open PowerShell or Command Prompt as Administrator and install the following:

# Install LLVM (required for compilation)
# Download from https://releases.llvm.org/download.html
# Install version 15.0 or later

# Install vcpkg for C++ dependencies
git clone https://github.com/Microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg integrate install

3. Install Sciter (for GUI)

Note: RustDesk uses Sciter for its GUI. You'll need to download the Sciter SDK. 
# Download Sciter SDK from https://sciter.com/
# Extract to a known location (e.g., C:\sciter-sdk)

Step 1: Clone the RustDesk Repository

git clone https://github.com/rustdesk/rustdesk.git
cd rustdesk

Step 2: Set Environment Variables

Set the following environment variables before building:

# PowerShell
$env:VCPKG_ROOT = "C:\path\to\vcpkg"
$env:LLVM_HOME = "C:\Program Files\LLVM"
$env:SCITER_SDK = "C:\path\to\sciter-sdk"

# Or set them permanently in System Environment Variables

Step 3: Install Rust Dependencies

# Update Rust to the latest stable version
rustup update stable

# Add the Windows MSVC target
rustup target add x86_64-pc-windows-msvc

# Install cargo-vcpkg for dependency management
cargo install cargo-vcpkg

Step 4: Configure Your Custom Build

Customize Branding and Settings

Before building, you can customize various aspects of your RustDesk client:

1. Modify Configuration Files

Edit src/rendezvous_messages.rs or Cargo.toml to customize:

  • Application name
  • Default server addresses
  • Company information

2. Custom Server Configuration

To point to your own RustDesk server, modify the default server settings:

// In src/common.rs or configuration files
// Change the default relay server address
pub const RENDEZVOUS_SERVERS: &[&str] = &[
    "your-server.com",
    // Add your custom server addresses
];

3. Customize Icons and Resources

  • Replace icons in the res/ directory
  • Modify icon.ico for the application icon
  • Update branding images and logos

Step 5: Build the Windows Client

Debug Build (for testing)

cargo build

Release Build (optimized)

cargo build --release
Tip: The release build will be much faster and smaller. Use this for distribution.

Build with Inline Plugin Support

cargo build --release --features inline

Step 6: Build the Installer (Optional)

Using NSIS (Nullsoft Scriptable Install System)

  1. Install NSIS from https://nsis.sourceforge.io/
  2. Navigate to the flutter\nsis directory
  3. Run the NSIS script: 
    makensis rustdesk.nsi

Using Inno Setup

  1. Install Inno Setup from https://jrsoftware.org/isinfo.php
  2. Open the .iss script file in the repository
  3. Compile the installer using Inno Setup

Step 7: Locate Your Built Binaries

After a successful build, your binaries will be located at:

  • Debug build: target\debug\rustdesk.exe
  • Release build: target\release\rustdesk.exe

Common Build Issues and Solutions

Issue: LLVM Not Found

Error: "Could not find LLVM"

Solution: Ensure LLVM is installed and the LLVM_HOME environment variable points to the installation directory.

$env:LLVM_HOME = "C:\Program Files\LLVM"

Issue: Sciter Library Not Found

Error: "Cannot find sciter DLL"

Solution: Set the SCITER_SDK environment variable to point to your Sciter SDK installation.

Issue: Missing C++ Build Tools

Error: "link.exe not found" or "MSVC not found"

Solution: Install Visual Studio 2022 with C++ development tools, or install the standalone Build Tools for Visual Studio.

Issue: Out of Memory During Compilation

Solution: Build with fewer parallel jobs:

cargo build --release -j 2

1. Custom Encryption Keys

2. Remove Update Checker

To disable automatic updates (useful for corporate deployments):

  • Comment out update-related code in src/ui.rs
  • Remove update server calls

3. White-Label Deployment

For complete rebranding:

  • Change all references to "RustDesk" in the source code
  • Replace all icons and images
  • Modify the application GUID in installer scripts
  • Update license and copyright information

Testing Your Custom Build

  1. Run the executable: .\target\release\rustdesk.exe
  2. Verify custom branding appears correctly
  3. Test connection to your custom server (if configured)
  4. Verify all features work as expected
  5. Test on a clean Windows installation

Distribution

Once you've built and tested your custom client:

  • Create an installer using NSIS or Inno Setup
  • Sign your executable with a code signing certificate
  • Document any custom configuration for your users
  • Consider creating a deployment package with configuration files

Keeping Your Build Updated

To update your custom build with the latest RustDesk changes:

# Update your local repository
git pull origin master

# Reapply your customizations (if needed)
# Rebuild
cargo build --release
Pro Tip: Keep your customizations in a separate branch or fork to easily merge upstream updates.
